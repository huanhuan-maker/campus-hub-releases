# 校园汇 Android 下载

[下载最新版 APK](https://github.com/huanhuan-maker/campus-hub-releases/releases/latest)

校园汇将趣智校园的洗澡功能和慧生活798的饮水功能整合在一个应用中。

- 支持 Android 8.0 及以上的 arm64 手机。
- 打开应用会检查正式新版，也可在“我的 → 设置 → 版本信息”中手动检查。
- 用户确认下载后，由 Android 系统完成覆盖安装；每次更新保持相同包名与签名。
- 分享 APK 不会包含分享者在手机上保存的登录信息，安装后请登录自己的用水账号并核对代扣绑定。

本仓库仅提供 APK、校验文件和更新说明。源码在私有仓库维护。
